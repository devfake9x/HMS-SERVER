Phase 03 • Priority: P1 Core Subsystems
Tích Hợp Phân Hệ Cốt Lõi: Relay DO, ADC Sensor & System Diagnostics
Xây dựng các endpoint nghiệp vụ chuyên biệt cho 4 kênh rơ-le số DO, giám sát tức thời 8 kênh cảm biến tương tự ADC, và các lệnh kiểm tra sức khỏe vi điều khiển.

  • Đọc điện áp/dòng điện tức thời 8 kênh analog 4-20mA / 0-10V
  • Chẩn đoán hệ điều hành: ping RTT, free heap, uptime
  • Bảo vệ lệnh reboot với token xác thực REBOOT-<DEVID>
Target: DeviceControlController.cs
Phase 04 • Priority: P2 Advanced Subsystems
Tích Hợp Phân Hệ Nâng Cao: Network, Modbus RS485, SMS & OTA

  • Quản lý Ethernet W5500, Wi-Fi Station, SoftAP và ưu tiên uplink
  • Cấu hình thanh ghi Modbus RS485, enforce 5000ms cooldown
  • Đọc tin nhắn SMS LTE phân trang an toàn (tối đa 10 tin/lần)
  • Quy trình 3 bước nâng cấp OTA kết hợp Secure Boot chữ ký số
Target: DeviceNetworkService.cs, DeviceOtaService.cs
